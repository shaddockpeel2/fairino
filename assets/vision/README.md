# YuNet face detector

`face_detection_yunet_2023mar.onnx` is the OpenCV 4.x compatible pretrained
YuNet face detector from the official OpenCV Zoo. It runs locally on CPU;
the existing RKNN garbage detector remains the object-classification model.

Source: https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet

SHA-256: `8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4`

The upstream MIT license is included as `YuNet-LICENSE`. Model preparation
requires internet only for this initial download; runtime is offline.
