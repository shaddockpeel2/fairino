# 2026-09-10 启动故障诊断（恢复待验证）

用户日志中 MoveIt 和真实硬件控制器已成功启动。MoveIt exit code -11 出现在 Ctrl+C 之后，不能据此判断启动失败。

相机 SN CH82C5201C9，固件 RD1017，SDK 1.10.35。RGB 与 Depth 均枚举为 USB 480 Mbps，经主机 6-1 与 6-1.3 两级 Hub。

实测：
- 原配置单独启动相机：持续 MJPEG 解码失败。
- 清除 LD_LIBRARY_PATH 和 Qt 插件路径再启动：同样失败。
- 仅在测试进程退出后，对 RGB 与 Depth USB 功能执行 USBDEVFS_RESET：仍失败。
- 软件重置后 20 秒审计：RGB 1 帧，Depth 174 帧，审计未通过，详见 report.json。
- SDK 枚举确认支持 640x480@10 YUYV。临时配置切换 YUYV 后出现 UVC payload header 无效、帧大小不符，审计也未通过。未修改默认配置。

结论：当前相机彩色数据链异常，尚未确定线缆、供电、Hub、设备状态或驱动中的具体根因。USB 枚举速度通过不等于图像数据健康。需要先断电重插，再复测，不能宣称已恢复。
