# 第五步 Demo 验证记录

统一入口：`scripts/target_follow/start_demo.sh`。日常操作见 `docs/目标跟踪Demo使用说明-20261008.md`。

三包构建通过，22 项 Python 检查和 4 项隔离 ROS 模拟检查通过。汇总为 `verification_summary.json`，测试报告为 `python_tests.xml` 和 `demo_ros_tests.xml`。

`mock_integration/` 保存统一入口的会话、原始执行日志、退出报告和启动日志：复用视觉数据源、记录/开始/状态查询/停止、目标暂停/恢复、重新开始、缺少检测时补启动、跟随中组件退出、当前默认配置待机、旧 SDK 所有者阻止启动。模拟场景的真实机械臂伺服指令数均为 0。默认配置待机检查没有覆盖实机碰撞减速效果；相关检查仍以第四步防碰撞记录为准。

第五步以用户确认可用的第四步作为实机基础，没有新增实机运动测试，也不要求一分钟演示。最初沙箱启动检查因本机 DDS 网络接口受限失败；后续检查在独立 ROS 域 196 完成，执行端使用 MockClient，视觉使用合成输入，没有打开真实相机或连接机械臂。
