## 静止数据说明了哪些问题

静止时基坐标 Roll/Pitch/Yaw 的全程峰峰值约为 **6.62° / 3.45° / 0.94°**。全部姿态相对平均旋转的角偏差中位数 0.99°、P95 2.35°、最大 3.69°；相对首帧的最大变化为 5.51°。这些反映本次固定目标的重复性，不是绝对角度误差或标定精度。

标签最短边中位数约 **29.94 px**，检测位置基本持续可用。PnP 两候选姿态夹角中位数 **25.62°**，重投影误差之差中位数 **0.169 px**，而当前歧义阈值为 0.15 px。曲线上误差差值频繁跨过阈值，造成拒绝与重新确认交替。由选中 PnP 解估计的标签法线与正视方向夹角中位数约 8.8°。这种小成像尺寸、接近正视的情况与平面双解的已知特征一致，这是依据数据作出的解释，尚没有独立姿态真值证明每个候选的正确性。

静止组全部选择候选索引 0，没有基坐标跳变拒绝；因此该组的主要现象是倾斜角波动和候选可区分度不足。姿态通过确认的连续片段只有 16 段，最长段从首帧到末帧约 0.69 秒。虽然单帧通过测量质量的比例约为 64%，但要求连续 5 帧使在线可用比例下降到 11.3%。

## 旋转数据的意义与限制

大幅转动本身仍提供了有用数据。该组的最大姿态变化约 166°、位置各轴跨度约 120/117/82 mm，包含实际手持动作；不能作为静止噪声，也不能用来直接断言姿态估计跳错。70 个连续性拒绝可能混合了快速真实转动、测量噪声与候选切换，当前记录没有逐动作标记或真值来分别判定。

观察期间有更稳定的片段，例如记录第 40–45 秒有 58/70 个观测通过确认，第 65–70 秒有 64/69 个通过确认。这说明当前单标签并非所有视角都不可用；还需用固定目标的对照采样确定可用视角。约第 70–76 秒存在标签丢失，随后第 75–85 秒的已配对观测全部为歧义，标签重新检测到后姿态没有立即恢复。这里的时间是相对首条记录的近似时间。

该组未严格执行三轴小角度往返，因此不能据此验收三轴符号、准确转角或可见范围。机械臂示教旋转下的基坐标稳定性也尚未实测。

## 为什么这会影响完整相对位姿跟随

用户选择的完整相对关系会让姿态误差同时影响 TCP 位置。用这轮静止法兰反馈和当前 TCP 配置作离线假设：以首个通过确认的方块位姿记录相对变换，方块到 TCP 的偏移长度约 221.7 mm；将全部记录的方块位姿直接、不经筛选或滤波地代入后续公式，假想 TCP 目标相对其坐标中位数的位移 P95 约 **10.1 mm**、最大约 **15.7 mm**，其中单独旋转项的 P95 约 9.2 mm。

这个计算包含被拒绝的观测，只用于显示噪声耦合；不是实际机械臂运动或第七步已实现的输出。实际控制仍需质量筛选、SO(3) 滤波、旋转死区以及位置/姿态联合限制。当前可用状态频繁中断，直接接完整跟随容易产生暂停与目标抖动。
