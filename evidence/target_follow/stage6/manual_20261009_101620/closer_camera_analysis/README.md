# 第六步：机械臂带相机靠近后的对照分析

日期：2026-10-09。用户确认：通过示教器移动机械臂靠近，相机安装支架未调整；方块保持上一轮旋转结束时的位置与朝向。本轮只分析原始文件，没有连接设备或发送运动指令。

## 结论

靠近后成像增大，位置重复性与通过确认的比例提高，但倾斜姿态仍有波动。另发现固定方块在两次观察位置下的基坐标读数相差约 **39.7 mm**，需先用一次连续的机械臂往返采样核实；尚不能据此确定是手眼标定、反馈坐标定义或其他因素造成。

靠近组没有跳变拒绝或候选索引切换，原始质量流没有标签丢失；机器人在该组内基本静止，法兰相对首帧旋转最大约 0.00156°。7 个本次启动进程正常退出。

两组之间经历了方块旋转和机器人换位，不能将变化全部归因于像素尺寸。由选中 PnP 姿态估计的法线视角中位数约 8.8°→5.5°，靠近组也更接近正视。候选误差差值仍接近当前 0.15 px 歧义阈值；放宽阈值或减少确认帧数不能证明姿态更准确。[IPPE 作者](https://github.com/tobycollins/IPPE#resolving-the-flip-ambiguity)说明，小物体、弱透视条件可能产生近似等价的平面姿态解，时间连续性不能保证选中正确解。本数据与这一特点相符，但没有绝对姿态真值。

## 固定方块跨观察位置的坐标差异

这里比较的是 **上一轮 `target_rotation` 最后 3 秒与新 `static_more_pixels`**，没有拿旋转前的旧静止组当作同一方块位姿。最后 3 秒按 `target_rotation` 的最后一条记录时间截取，含 44 个配对观测：22 个歧义、15 个确认中、7 个通过确认。

| 基坐标位置中位数 / mm | 靠近前：旋转记录末段 | 靠近后：新静止记录 |
| --- | ---: | ---: |
| X | -25.02 | -64.73 |
| Y | -523.46 | -524.01 |
| Z | 31.74 | 32.20 |

全部观测位置差约 `[-39.70, -0.54, +0.45] mm`，长度 39.71 mm；只使用通过姿态确认的 7/63 个观测，位置差仍约 **39.74 mm**。平均旋转相差约 7.49°，仅通过确认的观测平均旋转相差约 7.82°。末段是否在整个 3 秒内完全静止没有独立确认，且含姿态歧义；这些旋转均值不能作为绝对误差结论，也不能证明换算错误的具体来源。

机器人两组法兰位置中位数相差约 93.71 mm，平均旋转相差约 4.61°。新静止组的亚毫米离散度描述同一观察位置的重复性，不能证明换观察位置后基坐标仍正确。

按记录重建 `inverse(T_base_flange) × T_base_tag × inverse(T_camera_tag)`，两组得到相同的法兰到光学坐标变换，矩阵见 `comparison.json`。因此没有发现运行中使用不同手眼变换的迹象；该代数检查不能验证实际安装或标定是否正确。核查 SDK 固定轴 XYZ 欧拉角转换与本地实现一致，参见 [FAIRINO 数据结构说明](https://fairino-doc-en.readthedocs.io/3.8.0/SDKManual/CPPDataStructure.html)。历史手眼证据采用 ROS `flange_link` TF，当前链路采用 SDK 法兰反馈，二者坐标定义与模型一致性仍是后续排查项。仅凭两个观察位置不修改标定或旋转约定。

## 下一组：固定方块，机械臂往返

本轮优先在一次持续采样中核查坐标一致性。固定方块，不再更改相机安装；先退出原跟随 Demo。以下程序只记录，由用户使用示教器手动移动。

```bash
export FR3C_FOLLOW_DOMAIN_ID=187
/home/industio/fairino_ws/scripts/target_follow/start_orientation_check.sh --no-view \
  scenario:=robot_rotation duration_s:=60 \
  output_dir:=/home/industio/fairino_ws/evidence/target_follow/stage6/manual_20261009_101620/fixed_target_robot_motion
```

等终端开始持续输出 `Orientation:` 后按顺序操作，不要求精确卡秒：

1. 当前机器人位置记为 A，保持约 5 秒。
2. 姿态不变，在基坐标 Z 方向向上低速移动约 10–20 mm，远离方块，到 B 后保持约 5 秒。
3. 返回 A，保持约 5 秒。
4. 方块仍不动，再用示教器低速调整一次约 2–3° 的姿态，保持约 5 秒，回原姿态后保持约 5 秒。若示教器支持按基坐标 Rz 调整，优先用该轴；不强求 TCP 完全定点，分析使用实测法兰位姿。

全程保持标签可见以及夹爪、相机与桌面的间距。歧义状态也保留，不需要等每个位置都显示 `valid`。动作结束后等待程序自动结束；告知实际转动轴和是否完成返回，直接发送数据目录即可。

分析将比较 A→B→A 的目标基坐标、图像中的目标位姿和实际法兰变化，并区分平移、转动及静止段。只读审计已补录现有 `/target_follow/robot_feedback`，保留工具号、工件坐标号及变换；新增录制已通过隔离 ROS 模拟验证，不增加 SDK 调用。第六步仍在实测核查，第七至第十步尚未开发。
