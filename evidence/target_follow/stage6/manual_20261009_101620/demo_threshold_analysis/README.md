# Demo 要求放宽：当前问题与阈值回放

日期：2026-10-09。用户明确以可展示的 Demo 为目标，允许较大姿态误差、响应延迟及减弱旋转跟随，不要求标签每转 1°末端就精确转 1°。本轮没有连接设备或发运动指令。

## 当前现象

靠近后的静止记录原始质量有 264 个有效标签检测，没有标签丢失；247 个配对基坐标观测中，63 个通过检查、66 个姿态歧义、118 个等待连续确认。该组没有跳变拒绝，也没有候选索引切换。主要是持续有位姿读数，但倾斜角存在几度的波动；较保守的歧义筛选与 5 帧连续确认，又让“可用于跟随”的状态频繁中断。

因此，“检测不到标签”“没有姿态输出”“输出姿态有小幅波动”“没有连续通过质量检查”应分开看。90 秒旋转记录有丢失和跳变拒绝，包含用户确认的大幅真实动作，不能认定为每一项都是算法错误。

## 只改变筛选与确认的回放

重新按同一候选误差/夹角/索引计算歧义，保留原 PnP 位姿、时间戳、缺失事件及跳变检查，并重算提前失效事件。原 0.15 px、5 帧配置在三组数据中完整复现原报告配对状态计数。

| 歧义阈值 / 连续确认 | 原静止 | 靠近后静止 | 目标旋转 |
| --- | ---: | ---: | ---: |
| 0.15 px / 5 帧（原配置） | 11.3% | 25.5% | 36.2% |
| 0.15 px / 2 帧 | 40.2% | 53.4% | 51.1% |
| **0.10 px / 2 帧（本轮 Demo 起点）** | **78.1%** | **91.5%** | **62.2%** |
| 0.05 px / 2 帧（仅离线探索） | 97.4% | 99.6% | 68.4% |

表中是配对观测的可用比例，不是准确率或在线控制时间比例。0.10 px、2 帧在靠近组中，最长通过片段首末相隔约 3.42 秒；原配置约 0.77 秒。0.05 px 的改善在目标旋转组相对有限，同时放行更多不确定姿态，先采用 0.10 px 即可推进 Demo 预览，不要求原始姿态变成精密测量。

放宽并不会减少原始姿态误差，时间滤波也不保证选中正确平面解，依据见 [IPPE 作者说明](https://github.com/tobycollins/IPPE#resolving-the-flip-ambiguity)。本轮接受其作为粗略观测，以死区、滤波、小范围和低速实现可解释的演示；候选严重变化、跳变、过期与反馈异常仍有独立检查。

## 已实现：第六步 Demo 质量配置

`quality_profile:=demo` 选择 `config/tag_pose_demo.yaml` 与 `config/orientation_check_demo.yaml`，分别将歧义阈值改为 0.10 px、连续确认改为 2 帧。保守配置仍可用，命令行显式文件覆盖优先。

```bash
export FR3C_FOLLOW_DOMAIN_ID=187
/home/industio/fairino_ws/scripts/target_follow/start_orientation_check.sh --no-view \
  quality_profile:=demo scenario:=static duration_s:=20
```

这仍是只读检查。`valid` 表示通过所选 Demo 检查，不表示几度以内的真实精度。新配置不改变 PnP 选解或历史位置 Demo 的默认参数；显著次优分支、跳变、时间戳配对与过期检查沿用原逻辑。已有外部检测器被复用时不会被改参数，启动会提示它仍使用自己的歧义阈值；想应用完整 Demo 配置，应先退出旧检测/采样再启动。

会话记录新增质量配置名、实际请求的参数文件与检测器参数是否由本次启动应用。构建通过，保守/Demo 两项隔离 ROS 入口验证通过，实际确认帧数、外部检测器提示、只读记录和退出均检查成功。实测记录在此配置下的表现仍需后续运行观察，离线回放不替代实机结果。

## 后续预览与控制的 Demo 取舍

以下是第七至第九步设计起点，本轮还未实现滤波或机器人姿态控制：

| 处理 | Demo 起点 | 作用 |
| --- | --- | --- |
| 姿态低通 | 时间常数约 0.4 秒，SO(3)/四元数 | 用一些延迟减少倾斜角抖动 |
| 旋转死区/滞回 | 约 3°进入、2°退出 | 忽略小变化，比较累计变化以保留缓慢真实转动 |
| 旋转映射比例 | 默认 1.0；可选约 0.5 | 0.5 时目标转 10°，期望末端约转 5°；不同于只改变响应速度的闭环增益 |
| 短时质量波动 | 在最后可信观测仍新鲜的范围内冻结原目标 | 歧义/重新确认时避免立刻反复启停，不用坏帧更新目标 |
| 演示动作 | 缓慢约 5–15°的可见转动 | 检查方向、明显响应、停稳和停止，不追求逐度精确 |

死区施加于滤波后的累计旋转，相对上一次接受目标判断，避免每帧变化小就永远不响应。若使用 0.5 映射，旋转引起的位置偏移绕转也按同一映射计算；这种 Demo 是近似跟随，不能宣称保持实物目标到 TCP 的精确相对变换。映射比例 1.0 保留原关系设计，仍可用死区/滤波忽略小幅测量波动。

短时保持不重复刷新最后可信图像的时间戳，最长受原 350 ms 新鲜度约束。长期无可信观测、标签丢失、显著跳变或反馈过期仍暂停；原位置/速度/转角限制继续生效。约 40 mm 的跨视角位置差异与几度静态噪声不同，预览开发可以并行推进，接真实位姿运动前需用固定目标机械臂往返核实，避免将自身运动当成目标运动。
