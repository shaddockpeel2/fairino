# 2D 方块跟踪第四步记录（2026-09-22）

## 当前完成内容

- 新增单次短脉冲工具 `tools/stage4_direction_pulse.py`，支持 `base ±X/±Y` 和红色方块画面左、右、上、下四种方向。
- 每次最多 0.005 m/s、0.5 s，名义位移最多 2.5 mm；相机目标、TF、关节反馈、控制权与桌面碰撞物不满足前置条件时不申请控制权。
- 脉冲中监测目标、关节反馈、控制状态和 Servo 硬故障；异常或中断时发布零速度并请求释放控制权。
- JSON 记录像素误差、TCP/关节起止值、采样速度、Servo 和控制器消息数、场景物体以及租约时间。`--watchdog-test` 可记录停止心跳后的自动释放时间。
- 零速工具在控制器切换后取关节基线，并报告零命令漂移。

## 2026-09-22 现场验证

- 操作者确认机械臂、相机、线缆运动空间无障碍，并已验证可用的停止方法。
- 感知、Action、第四步计算及停止序列回归测试共 34 项通过。
- Action 的 `asyncio.sleep()` 在 rclpy 回调中引发 `no running event loop`，停止序列再次抛异常而产生空白结果。改用 executor 线程中的短时等待并保护停止序列后，独立 dry-run Action 的 2 秒超时返回 `OK`，取消返回 `CANCELED`（码 9，约 0.53 秒）。原名称重启后，3 秒 Goal 返回 `OK`，129 条 `TRACKING` 与 2 条短暂 `LOST_HOLD` 反馈。没有发布 Servo 命令。
- 彩色流实测约 6–8 FPS，偶发更长帧间隔。感知和 Action 的过期阈值从 0.25 秒调整为 0.40 秒并重启生效。
- 相机到 `base_link` TF 可用。用项目既有 `rviz_ground_plane` 几何加入 MoveIt 场景，并确认 Servo 场景收到该碰撞物。静态诊断：最近自碰撞距离 16.3 mm（慢速阈值 10 mm），场景距离 74.8 mm（阈值 20 mm），无碰撞。
- [零速测试](zero_speed_20260922.json)通过：最大关节变化约 3.8e-6 rad；Servo 状态 0；控制器释放到 `monitoring_manual_ready`。
- [零速心跳看门狗](zero_heartbeat_watchdog_20260922.json)通过：停止续租约 0.474 秒后桥接节点自动释放；控制器回到手动待命。
- 首次 [`base +X` 0.4 秒](base_x_plus_20260922.json)命令名义位移 2.0 mm，TCP 实测 +0.102 mm。该次工具旧判据误记为 `passed`，按现行判据应为 `undertravel`。
- [第二次 `base +X` 0.5 秒](base_x_plus_trace_20260922.json)名义 2.5 mm，实测 +0.135 mm；[连续心跳版复测](base_x_plus_continuous_20260922.json)实测 +0.119 mm，表明心跳间歇零命令不是主因。两次均记录为 `undertravel`，Servo 状态 0，控制器成功释放。Servo 目标关节增量也很小，低速响应问题发生在流式轨迹到物理位移的链路中，尚未定位具体环节。
- 随后停止 Servo 节点，移除临时地面碰撞物；`fairino3mt_execution_controller` 为 inactive，控制状态为 `monitoring_manual_ready`。

## 100 ms 周期复测

- 隔离 Servo 实例将输入、输出重映射到 `/fr3c_stage4/shadow_*`，实际控制器轨迹话题的发布者数保持 0。0.005 m/s、0.5 s 的同一输入下，20 ms 周期最大关节目标与反馈之差约 0.000286 rad；滤波系数 1.5 改为 1.01 后仍约 0.000285 rad；100 ms 周期为约 0.001408 rad。MoveIt Servo 每周期从实时关节状态起算、生成一个周期后的目标，因此短脉冲受轨迹点时距与下游跟随延迟共同影响。
- 真实 Servo 使用 100 ms 周期，保留 0.005 m/s 上限、0.5 s 单次脉冲和桌面场景。四个基坐标方向均按预期：[`+X`](base_x_plus_period_100ms_20260922.json) +0.715 mm、[`-X`](base_x_minus_period_100ms_20260922.json) -0.674 mm、[`+Y`](base_y_plus_period_100ms_20260922.json) +0.679 mm、[`-Y`](base_y_minus_period_100ms_20260922.json) -0.713 mm。四次 Servo 状态均为 0，控制器均释放至手动待命；最大绝对 Z 变化 0.093 mm，最大姿态变化 0.019°。实际位移约为名义 2.5 mm 的 27–29%，还有明显跟随滞后。
- 100 ms 周期重新做零速试验，最大关节变化约 7.6e-6 rad，Servo 状态 0，控制器正常释放。

- 四个视觉短脉冲均保持 0.005 m/s 输入上限、0.5 s 指令上限；每次 Servo 状态为 0、TCP Z/姿态无持续漂移、控制器释放回手动待命。视觉检测约有亚像素至 1 px 抖动，因此用方向一致且误差至少减小 0.5 px 作为 demo 判据。红块曾被操作者完全移出相机画面，感知明确输出 `target_not_found`，确认测试目标与检测框一致。
- 机械臂在零 Twist 发布后仍逐渐跟随先前单点轨迹，约 0.31–0.47 mm 的残余位移发生在零命令和释放流程中；正常释放后再观察 0.5 s，三次有记录的视觉脉冲残余位移均约 0.004–0.005 mm。此延迟必须计入后续闭环调参，不可把“发布零命令”视为机械臂瞬时静止。
- [运动中停止心跳](moving_watchdog_20260922.json)：0.5 s 预定脉冲在 0.345 s 中断，约 0.367 s 后自动释放控制权，累计 TCP 位移 0.249 mm；释放后 0.5 s 仍有 0.104 mm 跟随位移。该位移低于本轮 0.5 mm 的 demo 停止余量，但表明硬件侧有尾随响应。
- [运动中注入软件取消](moving_cancel_20260922.json)与[无效目标](moving_injected_target_loss_20260922.json)分别在约 0.251 s、0.256 s 停止非零命令，观察到真实 Servo 轨迹后均释放控制权；释放后 0.5 s 位移约 0.024 mm、0.035 mm。无效目标为工具注入，真实遮挡只验证了感知输出 `target_not_found`，没有把手伸入运行中的机械臂工作区。
- 原先单次 TF 差分出现 0.0097 m/s 尖峰，短于 10 ms 的采样间隔会放大离散关节状态变化，不能据此认定机械臂超速。工具改用 100 ms 窗口；同一 `base -Y` 方向[复测](base_y_minus_speed_window_20260922.json)最大估计 TCP 速度为 0.00166 m/s，[下方视觉脉冲](image_down_period_100ms_20260922.json)为 0.00190 m/s。两者均低于 0.005 m/s 输入上限。旧证据中的瞬时速度值不能用于速度门禁。
- 相机偶发长帧间隔曾导致短脉冲在申请控制权前、零速预备期或启动后 0.087 s 安全退出。工具现等待相机 TF 连通、在零速续租时等待新鲜目标，再发脉冲；脉冲中无效检测立即停止，目标超过 0.65 s 未更新也停止。失败的[下方预备期记录](image_down_precondition_abort_20260922.json)显示无非零指令且控制器正常释放。
- 测试结束移除临时桌面碰撞物并停止 Servo；`fairino3mt_execution_controller` 为 inactive，`/fairino/control_state` 为 `monitoring_manual_ready`，轨迹话题发布者数为 0。

## 当前判定

第四步的**低速 demo 门禁通过**：四个基坐标方向、四个画面方向、零速、软件中断、无效目标及心跳看门狗均得到正确方向或自动停止，且每次释放后回到手动待命。实际物理位移仍只有名义值的约 27–30%，停止后存在小于 0.5 mm 的短时尾随；实机 Action 取消和运动中真实遮挡尚未单独测试，进入第五步前应先用短时目标复核这两条路径。不得通过提高输入速度掩盖跟随滞后。
