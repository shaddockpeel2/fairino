## 8. 本机调用地址与运行目录

Qwen 和 TTS 对外提供本机 Unix Socket，使用 JSONL 协议。下表为当前默认路径，socket 文件由服务启动时创建；路径存在不等于服务健康。

| 接口 | 默认完整路径 | 路径来源 |
|---|---|---|
| Qwen 服务，GUI 等调用方使用 | `/home/industio/fairino_ws/evidence/voice/P3/runtime/fr3c-qwen-service.sock` | `qwen3vl.yaml` 的 `service.runtime_directory` + `service.socket_name` |
| Qwen Worker，服务内部使用 | `/home/industio/fairino_ws/evidence/voice/P3/runtime/qwen3vl-worker.sock` | Qwen 运行目录 + `worker.socket_name` |
| TTS 流式播报服务 | `/home/industio/fairino_ws/evidence/voice/P6/runtime/fr3c-tts-pipeline.sock` | `PipelineConfig.runtime_dir` + `socket_name` |

`FR3C_VOICE_RUNTIME_DIR` 可以覆盖 Qwen 的运行目录；TTS 可通过启动参数 `--runtime-dir` 覆盖运行目录。修改后需要同步调整调用方 socket 路径；完整启动脚本中也有默认 socket 路径。

ASR、KWS 由本地 Worker 管理，YOLO 在视觉节点内直接加载模型。这些入口没有现成的 HTTP API。

## 9. 修改或迁移时的配置对应关系

| 要调整的内容 | 应修改的位置 |
|---|---|
| Qwen 资产根目录 | `qwen3vl.yaml: assets.root` 或 `FR3C_QWEN_ASSET_ROOT` |
| Qwen 模型文件 | `qwen3vl.yaml: model.language_path`、`model.vision_path` |
| Qwen Worker 与运行库 | `qwen3vl.yaml: worker.binary_path`、`worker.rkllm_runtime_path`、`worker.rknn_runtime_path` |
| TTS 候选模型 | 启动参数 `--candidate`；候选定义在 `tts_candidates.json` |
| TTS 模型根目录 | `tts_service.py` 的 `PipelineConfig.asset_root` 或构造它的调用代码 |
| ASR 模型及运行库 | `asr.json: reference_root`、`model_directory`、`c_api_library`、`runtime_directory` |
| KWS 模型及 Python | `wake.json: kws_model_directory`、`kws_python` |
| 端侧视觉页面 YOLO 模型 | `edge_vision.yaml: objects.model_path` |
| 抓取感知节点 YOLO 模型 | launch 参数或 ROS 参数 `yolo_model_path` |
| 知识检索资产 | `qwen3vl.yaml: knowledge` 或 `FR3C_KNOWLEDGE_ROOT` |
| 人脸检测模型 | `edge_vision.yaml: faces.model_path` |

迁移工作区时还需保留或重建 `.venv-tts`、`.venv-yolo` 及外部模型依赖。模型资产和虚拟环境并非全部随 Git 仓库交付，仅复制源码不能保证上述绝对路径可用。
