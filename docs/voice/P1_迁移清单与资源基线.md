## 实测结果

证据根目录：`evidence/voice/P1/20260916`。每种条件只测一轮，各文本长度一个样本，不将范围当作P95。TTS cold为新backend加载但保留操作系统缓存；warm为已加载backend。Qwen固定4096上下文、测试输出上限64 token（生产原配置512），启动测试均加载语言和视觉模型，但本轮请求为文本。

| 条件 | 最低可用内存 MiB | Qwen启动秒 |
|---|---:|---:|
| 单独TTS | 5179.3 | — |
| 单独Qwen | 3305.2 | 4.92 |
| colors静止栈 | 5421.7 | — |
| colors+Qwen+TTS | 1032.6 | 6.04 |
| YOLO静止栈 | 5365.8 | — |

所有采样swap使用为0。初始空闲可用内存约6486 MiB。单独TTS进程观测RSS峰值约1340 MiB；共享页使RSS不可直接相加。各进程RSS和CPU峰值、每请求首PCM、生成时间见各目录summary.json，原始250ms采样在resources.jsonl。NPU负载节点不可读，sudo非交互读取也需要密码，记录为缺测而非0。

colors并发Qwen首token约0.14～0.39秒；预热TTS的10/30/60/120字RTF分别约1.41/1.27/1.19/1.09，均慢于播放消耗速度。单独TTS冷加载额外约3秒。此测试为固定文本TTS与独立Qwen请求并发，不是Qwen输出接TTS的端到端实现，不含真实播放。

最低1032.6 MiB距离参考1024 MiB阈值仅约9 MiB。尚未加入ASR/KWS、新对话GUI、RAG与512 token长回答，不能认定完整产品可常驻。阶段3需先处理生命周期、并发策略和内存余量；阶段5/6需处理TTS供给速度，不能仅扩大播放缓冲。

相机/感知/MoveIt/RViz两种模式均启动，colors与YOLO均出现 `rgbd_stream_stale` 和无目标状态。无模型YOLO也有陈旧帧，不能将其完全归因于Qwen；应对齐帧率与CPU调度继续分析。本轮没有可用目标抓取证据。MoveIt日志还记录未配置octomap插件、无FIFO调度权限等既有提示，保留原始日志。

静止测试使用真实机械臂与相机、mock夹爪、execute=false、run_p6_preflight=false，未调用抓取服务；P6证据隔离到本阶段目录。结束后停止本轮启动的栈与模型。GUI测的是RViz，不是尚未迁移的对话页。

## 复现

在工作区根目录执行，输出选一个新的运行目录：

```bash
python3 scripts/voice/p1_baseline.py inventory --output evidence/voice/P1/<新运行>/inventory
python3 scripts/voice/p1_baseline.py sample --output evidence/voice/P1/<新运行>/idle --duration 30
PYTHONDONTWRITEBYTECODE=1 /home/industio/DofbotPro_JetsonNano_0106/dofbot/.venv/bin/python scripts/voice/p1_benchmark.py --mode tts --output evidence/voice/P1/<新运行>/tts
# mode=qwen 测模型；mode=qwen_tts 测二者并发。
python3 scripts/voice/p1_summarize.py evidence/voice/P1/<新运行>/tts
```

现场已准备好时，静止栈另开终端：

```bash
FR3C_FIRST_GRASP_EXECUTE=false FR3C_RUN_P6_PREFLIGHT=false FR3C_GRIPPER_BACKEND=mock scripts/run_moveit_camera_rviz.sh detection_mode:=colors evidence_root:=/home/industio/fairino_ws/evidence/voice/P1/<新运行>/gate
```

YOLO基线将colors替换为yolo；先结束Qwen，不同时启动两个完整模型或两套抓取栈。模型测试持有本项目文件锁并检查已有Worker。测试日志不得回写旧项目。停止用启动终端Ctrl+C。

统一字段及时间点见 `P1_trace_schema.md`；固定文本见 `config/voice/p1_texts.json`。抓取回归22项通过，P1采样摘要回归2项通过，见grasp_regression.txt、p1_tests.txt。
