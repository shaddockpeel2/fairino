# 第九步：真实视觉位姿跟随

新增独立 `pose_follow` 驱动和 `start_pose_follow.sh` 入口，在已有图像时刻坐标换算、配对质量检查及第八步 ServoCart 执行能力上接入六自由度闭环。已有现场平移和倾斜跟随记录，最新范围与静止保持修正待现场确认；第八步已完成的三轴、组合和停止不需要重复。此步开始可以移动、转动方块，让机械臂一起跟随。

以能稳定演示为标准，允许明显延迟、几度姿态残差和位置误差。默认采用半幅旋转、较强滤波与宽死区；目标到 TCP 的完整相对关系在每次开始时重新记录，当前起点与历史位置不同也可以开始。半幅模式保持与“减幅后的目标”对应的关系，属于近似演示。

2026-10-10 三轮现场测试后修正：第一轮原始期望 TCP 位移约 100.9 mm，触发当时 100 mm 范围暂停；第二、三轮按 S 被姿态歧义/连续确认拒绝，未开始运动。当时将独立位置范围扩大到 200 mm，第九步检测改用 `tag_pose_demo_follow.yaml`，允许候选旋转差异在 35°内的近似解。两帧确认、基坐标连续性、滤波/死区和半幅映射继续生效；35°是两个视觉候选解的差异容差，机械臂转角范围当时仍为 20°。该次修复已做数据回放和模拟。

随后一轮现场平移可跟随，但倾斜触发姿态跳变，恢复时原始姿态差 20.24°刚超过当时 20°恢复阈值，进入等待 S 重记录。该次修正后第九步使用独立 `orientation_check_pose_demo.yaml`，观测抖动余量扩大到 25°（另加原有角速度×图像间隔），原始目标的恢复转角容差扩大到 40°。这些是滤波前观测容差，当时实际运动范围仍为 20°，0.8 s 姿态滤波、6°/4°死区、0.5 映射与 3°/s 限速继续生效。诊断见 [倾斜修正](../evidence/target_follow/stage9/tilt_tuning_20261010/README.md)。

最新会话 `20261010_140121_208977` 已运行 14049 次 ServoCart，全部返回 0；最后方块相对开始转约 40.71°，半幅期望转角 20.36°超过旧 20°上限，进入 `paused_reteach`，退出报告的 `signal` 是后续关闭原因。现将 TCP 三维半径扩大到 **500 mm**、相对开始 TCP 转角扩大到 **90°**，暂停恢复原始目标差值改为 **150 mm／120°**。速度、加速度、实际反馈和参考超前检查继续生效。

用户随后要求将区域改为 1 米、保持速度参数：当前 `follow_radius_m=1.00`，即每次 S 开始时实际 TCP 周围的三维半径 1 米；姿态范围 90°、半幅映射和静止保持参数不变。最新会话 `20261010_142209_226469` 最后返回 SDK 112（本地 SDK 定义为“目标位姿无法到达”），没有触发旧 500 mm 软件半径。扩大软件半径不会改变机器人实际可达空间，该错误仍由原有停止流程处理。记录见 [1 米区域修正](../evidence/target_follow/stage9/radius_1m_20261010/README.md)。

## 现场使用

1. 机器人和方块先停稳，标签清楚可见。T 记录时，期望 TCP 应与实际 TCP 重合；随后 S 开始，先看方块静止时机械臂是否基本停稳。
2. 方块仍平放，缓慢做约 15–20°的水平转动，停留数秒，观察末端出现明显、平滑的减幅旋转及位置绕转，然后大致返回即可。
3. 平移约 15–30 mm，再小幅前后、左右倾斜，保持标签可见；可以把平移与转动组合，不需要量角或达到严格误差表。
4. 短暂遮挡再放开，观察是否暂停、数据恢复后平滑继续；大幅移动被遮挡方块时，程序可能要求 S 重新记录，按提示操作。
5. X 主动停止，再 S 开始，确认用当前实际位置重新记录，没有跳回历史起点。最后 Ctrl-C 退出即可。

死区和目标锁存作用于滤波后的累计变化，半幅映射还会减小动作，几毫米或几度的小动作可能被忽略；用明显但缓慢的转动观察即可。停住后允许残差和延迟，不要求目标每转 1°机器人精确跟随 1°。

此前记录中约 40 mm 的跨视角基坐标差异没有被这次软件验证解释。首次真实运行时同时查看固定方块的基坐标是否出现明显漂移，以及机器人是否持续追赶静止方块；若出现，X 停止并保留本轮日志核查坐标链/观测。这里只做运行合理性检查，不要求先完成一套精密姿态标定或重复前八步。

配置在 `src/fr3c_follow_driver/config/pose_follow.yaml`，启动时读取，修改后退出重启：

| 参数 | 当前值 |
| --- | --- |
| 位置/姿态低通 | 0.25 s / 0.8 s |
| 目标旋转死区 | 6°进入 / 4°退出 |
| 视觉候选旋转差异容差 | 第九步 35°；原只读 Demo/保守配置仍为 5° |
| 基坐标观测连续性 | 第九步 25°抖动余量 + 60°/s × 图像间隔；旧只读 Demo 仍为 6°余量 |
| 旋转映射 | 0.5，旋转与位置绕转共同减幅 |
| 到达容差 | 位置 4 mm / 姿态 2°，进入固定参考保持 |
| 接受新目标 | 完整期望 TCP 相对固定视觉基准超过 8 mm 或 4°，新可信帧同向确认 0.2 s |
| 线速度/加速度 | 20 mm/s / 60 mm/s² |
| 角速度/角加速度 | 3°/s / 10°/s² |
| 范围 | 本轮起始 TCP 周围三维半径 1000 mm，姿态距起始 90° |
| 参考超前 | 相对实际反馈 15 mm / 5° |
| 可信目标/反馈超时 | 350 ms / 200 ms |

1 米是三维直线距离，不是每个轴都能移动 1 米；原始可信目标、滤波目标、实际 TCP 和发送参考均检查，不能用滤波掩盖越界。长偏移下旋转会带来位置绕转，可能先触发位置范围。视觉越界或大幅恢复变化会暂停并提示 S 重新记录当前关系，不自动跳追。

## 质量、暂停与恢复

| 状态 | 含义与操作 |
| --- | --- |
| `idle` / `stopped` | 待机或主动停止，T 记录、S 开始 |
| `following` | 正常跟随；`settled_hold: true` 表示已到位保持，仍保留伺服会话 |
| `holding_quality` | 短暂歧义/重新确认，保持上次接受的完整目标 |
| `paused_target` | 丢失、跳变、可信图像过期或正在等待新的可信图像；可信数据恢复后自动接续 |
| `paused_feedback` | 反馈重复过期、读取失败或非法位姿；停止伺服，等反馈和新可信图像恢复 |
| `paused_reteach` | 目标超出当前关系范围或暂停期间大幅重定位；S 明确重新记录后开始 |
| `paused_collision` | 可选模型预测要求等待、减速到零或暂停；检查可用后接续 |
| `fault` | SDK、停止接口或控制器故障、实际/参考位姿范围或超前异常；处理原因后重启驱动 |

保持期间坏帧不会更新目标或刷新可信图像时间戳，最多沿最后可信目标收敛到新鲜度截止。实际暂停会结束当前伺服，恢复必须有新的可信观测，从实际 TCP 重新锚定参考并清零线/角速度，保留原相对关系和滤波/死区基准。重新确认中的软状态只可保持已运行的会话，不能单独让已暂停的伺服重新启动。
