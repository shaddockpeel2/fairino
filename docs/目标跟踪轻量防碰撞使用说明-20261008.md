# 目标跟踪轻量防碰撞使用说明

2026-10-08。用于第四步 XYZ 跟随，沿用前面已经验证的视觉转换、固定末端姿态和原厂 ServoCart 执行方式。

## 选择跟踪模式（现场复测后更新）

按用户要求改为启动时可选，**当前默认回到加入模型防碰撞之前的跟踪模式**。速度、加速度和跟随范围沿用现有配置；原有控制器故障/碰撞状态、反馈超时、目标丢失和主动停止处理继续有效。

```bash
# 之前的跟踪流程：不加载碰撞模型，不启动预测/检查线程
scripts/target_follow/start_follow.sh collision_enabled:=false

# 新增模型防碰撞流程
scripts/target_follow/start_follow.sh collision_enabled:=true
```

使用单入口 Demo 时同样选择：

```bash
scripts/target_follow/start_demo.sh collision_enabled:=false
scripts/target_follow/start_demo.sh collision_enabled:=true
```

切换前先 X 停止，再 Ctrl-C 退出执行端/当前 Demo，重新启动所选模式，按 S 记录新偏移并开始。这个参数在启动后只读，运行中用 `ros2 param set` 会被拒绝，不在运动中切换模式。两种启动方式都先待机。

不传该参数时读取 `driver_params_file` 的 `collision_enabled`，默认文件为 false；命令行 true/false 优先于参数文件。两种模式共用同一套速度/加速度/范围配置，不需要维护两份控制参数。

查看器显示 `Model collision: OFF | legacy following` 或 `Model collision: ON`。`follow_control.sh status` 始终输出 `collision.enabled`；报告记录 `tracking_mode: legacy/collision_guarded`。关闭模式没有新增的模型自碰撞/桌面预检，不会自动识别并避开桌面。

现场这一轮防碰撞出现大量等待方向检查导致的启停；切换功能用于回归对照，开启模式的原有检查算法保留，尚未据此宣称 Z 方向卡顿已修复。

## 本次加入的能力

- 复用抓取/分类动作使用的 FR3C 本体网格、夹爪本体与四指、相机外壳和 SRDF 相邻连接豁免。
- 固定工作台为 `base_link` 的 XY 平面，默认上表面 Z=0、长宽各 2 m、厚 20 mm。只允许安装底座与工作台接触；机械臂活动部件和末端附件都参加检查。
- 夹指沿用已有尺寸，扩大为从空夹闭合到模型 60 mm 释放开度的扫掠包络；当前追踪链路没有读取夹爪开度。只额外允许同侧两片对向夹指的正常闭合接触，夹指与其他部件/桌面的碰撞仍检查。
- 根据实测关节和法兰，检查当前自碰撞、桌面碰撞，并沿当前速度和期望平移方向预测一小段运动。短段逆解从实测关节出发，检查局部关节插值。预测包含已发参考超前、后台结果寿命和配置加速度对应的制动距离。
- 接近障碍减速，继续接近时 StopMotion/ServoMoveEnd，显示 `paused_collision`；目标转向可安全运动的方向后保留原偏移自动恢复。X 主动停止后，需要重新 S 才开始。

后台使用 MoveIt/FCL 的本地场景，不需要另外启动 move_group、ros2_control 或点云。视觉和 SDK 主循环不等待碰撞计算；后台覆盖旧请求，只处理最新数据。没有有效检查结果、结果过期或新运动方向尚未检查时先暂停。

这是固定场景的在线减速/停止保护。没有建模的手、其他物品、线缆、夹持物不会被识别；相机外壳仍沿用近似安装几何。ServoCart 的内部逆解由控制器执行，后台预测依赖局部连续分支，不能作为对实际连续运动的完整认证，也不是人员安全功能。

## 当前参数

文件：`src/fr3c_follow_driver/config/position_follow.yaml`，修改后重启执行端。

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| `collision_enabled` | false | 关闭新增模型检查，使用之前的跟踪流程；true 为开启 |
| `max_speed_m_s` | 0.020 | 20 mm/s，保留现场调整值 |
| `max_accel_m_s2` | 0.060 | 60 mm/s²，保留现场调整值 |
| `follow_radius_m` | 1.00 | 本轮起点周围的跟随范围，保留现场调整值 |
| `table_z_m` | 0.0 | **桌面相对 base_link 的高度**，不是相机坐标或 TCP 高度 |
| `table_size_m` | 2.0 | 以机器人基坐标原点为中心的正方形边长 |
| `collision_margin_m` | 0.005 | 预测进入约 5 mm 余量时暂停 |
| `collision_slow_distance_m` | 0.020 | 接近碰撞对时的距离查询与减速范围 |

后台调度间隔默认 20 ms，结果寿命默认 150 ms；实际后台频率受检查耗时影响。距离超过查询范围时记录为 20 mm、碰撞对为 `outside_distance_band`，表示至少超过查询范围。正常固定连接距离不因数值较小持续限速；运动预测使间距变小时才减速。

上述数值是低速演示起点，不要求额外误差或帧率指标达标。机械臂基座就装在工作台面上时通常可以先用 Z=0；有垫高安装时，要按实际桌面相对基座的高度设置。扩大跟随范围不会扩大已建模的工作台，也不会引入其他障碍物。

## 启动和验证步骤

本工作区已经构建。已运行旧追踪时，先在查看器按 **X** 停止，再到旧执行端终端 **Ctrl-C**。相机/标签终端可以继续复用；查看器也退出后重开，以加载碰撞显示。

需要重新构建时：

```bash
cd /home/industio/fairino_ws
source scripts/camera/activate.bash
colcon build --packages-select fr3c_follow_driver fr3c_target_follow --symlink-install
```

终端 1：已有相机与标签检测时继续使用；没有时运行：

```bash
cd /home/industio/fairino_ws
scripts/target_follow/start_pose.sh
```

终端 2：启动新版执行端，启动后保持待机：

```bash
cd /home/industio/fairino_ws
scripts/target_follow/start_follow.sh collision_enabled:=true
```

终端 3：打开查看器：

```bash
cd /home/industio/fairino_ws
scripts/target_follow/view_pose.sh
```

1. 确认工作台高度与模型一致，机械臂处于自动模式、已使能、无控制器故障，工具 0/工件 0 为零变换。
2. 本节验证的是开启模式，等待界面出现 `Model collision: ON` 一行。如果开始被拒绝，看终端的服务回复和碰撞原因，先核对桌面高度与模型。
3. 标签完整可见时按 **S**，先在合适高度小幅移动 X/Y，确认跟踪仍正常。S 会重新记录当前偏移和固定旋转。
4. 在合适起始位置缓慢改变目标高度，使期望 TCP 靠近已设置的桌面；观察限速比例下降，继续靠近时出现 `COLLISION PAUSE | paused_collision`。无需也不要故意让夹指接触桌面。
5. 将目标向远离桌面的方向移动，确认恢复跟随；原偏移保留。最后 **X** 主动停止，移动标签后机械臂应保持停止。

另外开一个终端可查看完整诊断：

```bash
cd /home/industio/fairino_ws
source scripts/camera/activate.bash
export ROS_DOMAIN_ID=187 ROS_LOCALHOST_ONLY=1
ros2 topic echo /target_follow/follow_state --once
```

`collision` 字段包含当前/预测距离、碰撞对、速度比例、检查耗时、检查年龄和原因。每轮 `samples.jsonl` 新增实测关节反馈；`report.json` 包含 `collision_check_ms`、`collision_pauses` 与原有伺服发送间隔，便于判断是否拖慢刷新。

`collision_margin` 表示碰撞余量暂停；`collision_prediction_unavailable` 表示短段逆解失败；`robot model and SDK flange feedback disagree` 表示关节反馈与模型不一致；`collision_check_pending_or_expired` 表示正在等待有效检查。控制器自身故障、反馈丢失和范围越界仍按原来的 fault 处理。

## 软件验证

实际 URDF/SRDF 的 C++ 测试覆盖模型/FK 与局部逆解、自碰撞、末端附件接近桌面的提前暂停及退离、模型不一致、结果过期和方向变化。ROS 模拟使用关节/法兰一致的 Mock SDK，覆盖带检查的正常跟随、桌面暂停、不再发送和目标反向恢复。模拟不连接机械臂。

```bash
cd /home/industio/fairino_ws
source scripts/camera/activate.bash
colcon test --packages-select fr3c_follow_driver
ROS_DOMAIN_ID=191 ROS_LOCALHOST_ONLY=1 FR3C_RUN_ROS_TESTS=1 \
  ROS_LOG_DIR="$PWD/evidence/target_follow/stage4/test_ros_logs" \
  python3 -m pytest -q src/fr3c_follow_driver/test/test_follow_mock.py \
  src/fr3c_follow_driver/test/test_collision_mock.py
```

实机的减速、桌面暂停与恢复仍需按上面的步骤验证；本次开发没有向真实机械臂发送运动命令。
