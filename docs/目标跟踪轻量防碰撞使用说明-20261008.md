# 目标跟踪轻量防碰撞使用说明

初版：2026-10-08；完整启动流程补充：2026-10-09。

用于第四步 XYZ 跟随，沿用前面已经验证的标签识别、图像时刻坐标转换、手眼/TCP 标定、固定末端姿态和原厂 ServoCart 执行方式。**当前默认关闭新增模型防碰撞，回到加入该功能之前的跟踪流程。**

完整顺序：设备准备 → 退出旧执行端 → 按需构建 → 选择启动方式和防碰撞模式 → 确认待机及模式 → S 开始跟随 → X 停止 → 退出执行端。

## 1. 启动前准备

1. 机械臂、控制器和相机正常上电，电脑连接机器人网络及相机 USB。默认机器人 IP 为 `192.168.58.2`。
2. 在示教器确认自动模式、已使能、机械臂静止，且没有急停、控制器故障或碰撞报警；没有其他机器人程序正在执行。本程序不会自动切换模式、使能机械臂或清除控制器报警。
3. 当前执行方式使用工具 0、工件 0，并要求它们的坐标变换为零；TCP 偏移由已有标定文件处理。
4. 沿用现有夹爪/相机安装和已验证的标定：`/home/industio/fairino_ws/src/fairino3mt_v6_moveit2_config/config/dabai_dcw2_handeye.yaml` 与同目录的 `ydi_j22_tcp.yaml`。附件安装变化后，需要先核对标定。
5. 将方块顶部的 20 mm AprilTag36h11、ID 1 标签完整放进相机视野。先让方块和机械臂停住，准备从当前位置记录跟随偏移。
6. 如果之前已经打开执行端，在原查看器按 **X**，再到原执行端或 Demo 终端按 **Ctrl-C**。旧反馈端、预览端、ServoCart 探针及其他会控制机械臂的程序也要退出；相机与标签检测可复用。

设备重启后，电脑上的旧执行端仍需退出。若法兰灯仍红或示教器仍有故障，先查看控制器的具体报警和状态，恢复后再启动；不能仅凭红灯判断是状态反馈通信断开。

两种启动方式共用这套准备步骤。**下面的单入口 Demo 和分终端方式选一种，不要同时运行两个执行端。** 当前直接跟踪链路不需要额外启动 move_group、ros2_control 或之前的抓取/分类动作执行端。

### ROS 域与参数优先级

实机脚本默认使用 `ROS_DOMAIN_ID=187`、`ROS_LOCALHOST_ONLY=1`。如果之前已用 `FR3C_FOLLOW_DOMAIN_ID` 自定义域，需要让相机、执行端、查看器和控制终端使用相同值；这些脚本通过该变量选择域。不要把模拟域与实机域混用。

不传 `collision_enabled` 时，启动器读取 `driver_params_file` 的配置；当前默认文件为 `false`。命令行显式 `true/false` 优先于参数文件。两种模式共用速度、加速度及范围参数。

`collision_enabled` **只在启动时选择，启动后只读**，运行中 `ros2 param set` 会被拒绝。切换按第 6 节重启执行端。

## 4. 确认当前模式和待机状态

查看器应有图像、标签及实际 TCP/目标坐标，执行端状态为 `idle`，尚未请求跟随。标签或反馈仍显示 waiting 时，先等数据恢复并查看对应终端。

判断新增模型防碰撞是否开启：

| 模式 | 查看器显示 | `follow_control.sh status` 中的字段 |
| --- | --- | --- |
| 关闭 | `Model collision: OFF | legacy following` | `tracking_mode: legacy`，`collision.enabled: false`，`collision.reason: disabled` |
| 开启 | `Model collision: ON`，可能附带距离、速度比例或 waiting | `tracking_mode: collision_guarded`，`collision.enabled: true` |

也可随时在另一个终端查询：

```bash
cd /home/industio/fairino_ws
scripts/target_follow/follow_control.sh status
```

开启模式的 `collision.ready` 表示已经产生过检查结果，仍要结合 `reason`、`age_ms`、`speed_scale` 和跟随状态判断；只有 ON/ready 不能说明当前正在跟随或当前结果仍有效。

关闭模式不会加载碰撞模型、进行预测逆解或运行新增检查线程。原有控制器故障/碰撞状态、反馈超时、目标丢失、范围限制和主动停止处理保留；**关闭模式没有模型自碰撞/桌面预检，不会自动识别并避开桌面。** 本开关不修改控制器自身的碰撞检测设置。

## 5. 开始跟随与日常验证

1. 确认机械臂周围有可运动空间，方块标签完整可见，机械臂和方块暂时静止。开启模式还需确认工作台模型高度正确。
2. 点击查看器使窗口获得键盘焦点，按 **S**。S 会重新记录当前 TCP 相对标签的位置偏移，并固定当前法兰旋转，然后开始 XYZ 跟随。无需先按 T。
3. 确认界面进入 `FOLLOW ON | following`，再小幅移动方块 X/Y，随后小幅改变 Z，观察实际 TCP 跟随。跟踪驱动平移，不随标签旋转改变机械臂姿态。
4. 让方块停住，机械臂应收敛到对应位置。遮挡或移出标签会进入 `paused_target`；标签重新可见且数据正常时，会保留原偏移自动恢复。如果不希望恢复，按 X。
5. 完成本轮后按 **X**，确认 `stopped` 和机械臂停止。此后移动方块不会自动开始跟随；重新按 S 开始新一轮并记录新偏移。

| 按键 | 功能 |
| --- | --- |
| T | 在停止状态记录当前偏移，不启动运动；S 本身也会重新记录 |
| S | 记录当前偏移和固定旋转，开始本轮跟随 |
| X | 主动停止并结束本轮，之后需 S 才能再次跟随 |
| Q / Esc / 关闭窗口 | 关闭查看器；是否同时退出执行端取决于窗口启动方式，见第 7 节 |

没有查看器时，在另一个终端按需执行以下命令，**开始和停止是两个独立操作**。

开始跟随（等同 S）：

```bash
cd /home/industio/fairino_ws
scripts/target_follow/follow_control.sh start
```

停止跟随（等同 X）：

```bash
cd /home/industio/fairino_ws
scripts/target_follow/follow_control.sh stop
```

可选：只记录偏移、保持停止，使用 `scripts/target_follow/follow_control.sh teach`。

### 开启模式的防碰撞观察

正常跟随确认后，在有足够空间的起始位置缓慢改变目标高度，观察模型接近桌面时速度比例是否下降、是否进入 `COLLISION PAUSE | paused_collision`。不需要让夹指实际接触桌面。

目标转向远离桌面、且新方向检查允许运动时，应保留原偏移自动恢复。若反复暂停或 Z 上升卡顿，先按 X，保存这一轮日志，再按第 6 节切回关闭模式做对照。检查等待、过期或预测失败也会暂停，不能把每次 `paused_collision` 都当成已发生实物碰撞。

## 6. 切换防碰撞模式

1. 在查看器按 X，或执行 `follow_control.sh stop`，确认已经停止。
2. 到执行端终端按 Ctrl-C；使用单入口 Demo 时，到 Demo 终端按 Ctrl-C。
3. 重新执行第 3 节所选方式的命令：`collision_enabled:=false` 回到之前的流程，`collision_enabled:=true` 开启模型检查。
4. 用第 4 节确认 OFF/ON，再按 S 记录当前新偏移并开始。

分终端方式只切换执行端时，相机、标签检测和已有查看器可继续运行。查看器源码更新后需重开窗口才能加载新版显示。单入口 Demo 退出后，会结束它自己启动的节点；原来就运行、被复用的相机/检测/查看器不随它退出。

如需修改默认模式，编辑 `/home/industio/fairino_ws/src/fr3c_follow_driver/config/position_follow.yaml` 中的 `collision_enabled`，随后重启执行端。使用本工作区的 symlink-install 配置；非链接安装需要重新构建/安装配置。显式命令行 true/false 仍优先于文件。

## 7. 正常停止与全部退出

1. **先 X 或 `follow_control.sh stop`。** 控制脚本会等待停止状态，并检查 SDK 停止返回值；正常会输出 `Driver stopped` 和 StopMotion/ServoMoveEnd 的结果。只看到停止请求的服务回复，不等于已确认停止。
2. **再 Ctrl-C 退出执行端或 Demo。** 执行端退出时写出本轮报告。
3. 分终端方式：关闭查看器，最后按需 Ctrl-C 退出相机/标签检测终端。

单入口 Demo 自己启动的查看器，按 Q/Esc 或关闭窗口会触发整个 Demo 退出及执行端停止。独立 `view_pose.sh` 的窗口，或 Demo 复用的已有窗口，关闭时只退出查看器，**不会替你停止执行端**；仍需先 X 或使用 stop 命令。统一按“先停止，再退出”的顺序操作最容易确认状态。

如果停止命令超时、SDK stop/end 非零或机械臂仍在异常运动，先用示教器停止/急停并检查控制器；软件回复不能代替现场停止确认。

## 8. 暂停、故障与设备重启后的恢复

| 现象 | 查看与处理 |
| --- | --- |
| 提示已有 feedback/preview/servo 或重复发布者 | 退出旧反馈、预览、执行端及重复相机/检测链路，再启动；保留一套执行端 |
| 无图像、无标签、启动提示先 start_pose | 查看相机/标签终端、USB 与标签可见性；分终端先运行 start_pose，确认所有终端在同一 ROS 域 |
| S/start 被拒绝 | 查看服务回复和状态中的 reason；常见为目标/反馈未就绪、非自动模式、未使能、工具/工件配置或控制器故障；开启模式还需检查模型/桌面配置 |
| `paused_target` | 目标缺失或过期，恢复标签后可能自动继续；要结束这一轮就 X |
| `paused_collision` | 查看 `collision.reason` 和速度比例；可能是距离余量、预测逆解、等待新方向或结果过期。退离方向通过检查后可能自动继续，X 可结束本轮 |
| 跟随范围越界、反馈超时、控制器报警，界面 `FAULT - CHECK DRIVER` | 先停止并退出执行端，查看 reason 和示教器；解决原因后重新启动，再 S 记录新偏移 |
| `ServoCart failed: -4` 或法兰灯红 | 保留日志并查看示教器具体报警；-4 在当前 SDK 中是 XML-RPC 命令失败，单凭该码或红灯不能确认反馈通信断开。恢复设备状态后退出旧执行端，再重新启动 |

碰撞原因例子：`collision_margin` 为余量暂停；`collision_prediction_unavailable` 为短段逆解失败；`collision_check_pending_or_expired` 为等待有效结果；`robot model and SDK flange feedback disagree` 为关节模型与法兰反馈不一致。

fault 后不要反复按 S 试图直接恢复。按“停止 → 退出旧执行端 → 处理故障/必要时重启设备 → 确认第 1 节条件 → 重新启动 → 确认模式 → S”操作。程序不会替用户清除控制器故障。

## 10. 模型能力与当前参数

### 开启模式加入的能力

- 复用抓取/分类动作使用的 FR3C 本体网格、夹爪本体与四指、相机外壳和 SRDF 相邻连接豁免。
- 固定工作台为 `base_link` 的 XY 平面，默认上表面 Z=0、长宽各 2 m、厚 20 mm。只允许安装底座与工作台接触；机械臂活动部件和末端附件都参加检查。
- 夹指沿用已有尺寸，扩大为从空夹闭合到模型 60 mm 释放开度的扫掠包络；当前追踪链路没有读取夹爪开度。只额外允许同侧两片对向夹指的正常闭合接触，夹指与其他部件/桌面的碰撞仍检查。
- 根据实测关节和法兰，检查当前自碰撞、桌面碰撞，并沿当前速度和期望平移方向预测一小段运动。短段逆解从实测关节出发，检查局部关节插值。预测包含已发参考超前、后台结果寿命和配置加速度对应的制动距离。
- 接近障碍减速，继续接近时 StopMotion/ServoMoveEnd，显示 `paused_collision`；目标转向可安全运动的方向后保留原偏移自动恢复。X 主动停止后，需要重新 S 才开始。

后台使用 MoveIt/FCL 的本地场景，不需要另外启动 move_group、ros2_control 或点云。视觉和 SDK 主循环不等待碰撞计算；后台覆盖旧请求，只处理最新数据。没有有效检查结果、结果过期或新运动方向尚未检查时先暂停。

这是固定场景的在线减速/停止保护。没有建模的手、其他物品、线缆、夹持物不会被识别；相机外壳仍沿用近似安装几何。ServoCart 的内部逆解由控制器执行，后台预测依赖局部连续分支，不能作为对实际连续运动的完整认证，也不是人员安全功能。

| `table_z_m` | 0.0 | **桌面相对 base_link 的高度**，不是相机坐标或 TCP 高度 |
| `table_size_m` | 2.0 | 以机器人基坐标原点为中心的正方形边长 |
| `collision_margin_m` | 0.005 | 预测进入约 5 mm 余量时暂停 |
| `collision_slow_distance_m` | 0.020 | 接近碰撞对时的距离查询与减速范围 |

后台调度间隔默认 20 ms，结果寿命默认 150 ms；实际后台频率受检查耗时影响。距离超过查询范围时记录为 20 mm、碰撞对为 `outside_distance_band`，表示至少超过查询范围。正常固定连接距离不因数值较小持续限速；运动预测使间距变小时才减速。

上述数值是低速演示起点，不要求额外误差或帧率指标达标。机械臂基座就装在工作台面上时通常可以先用 Z=0；有垫高安装时，要按实际桌面相对基座的高度设置。1.00 m 是本轮起点周围的范围，不是累计行程，也不代表防碰撞。扩大跟随范围不会扩大已建模的工作台，也不会引入其他障碍物。
