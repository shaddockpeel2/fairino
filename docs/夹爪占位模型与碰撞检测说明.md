# FR3-C 固定夹爪占位模型与碰撞检测

日期：2026-09-08。

## 当前实现

- `src/fairino_description/urdf/fairino3_mt_v6.urdf`：给全部 7 个本体连杆补充 collision，复用各自官方 STL 和 visual 原点；不改变关节运动学及限位，也不修改 STL。
- `src/fairino_description/urdf/ydi_j22_placeholder.xacro`：固定四指外观、历史垫片占位和整体盒形碰撞包络；`grasp_frame` 使用独立实测值。
- `src/fairino3mt_v6_moveit2_config/config/fairino3mt_v6_robot.urdf.xacro`：默认加载夹爪；通过现有 MoveItConfigsBuilder 启动的 demo/MTC 环境均使用此模型。
- SRDF 仅排除相邻本体连杆及夹爪安装接触对；非相邻本体、夹爪对其他本体连杆的碰撞仍检测。
- 保留原六轴规划组和六个可动关节，将 MoveIt 链终点从 `flange_link` 延伸到固定连接的 `grasp_frame`，使 RViz/MTC 的笛卡尔末端就是夹爪尖端。`gripper_command_joint` 属于独立夹爪组，只表达开度，不改变机械臂六轴自由度。

## 依据与尚未标定的参数

底部方形板连接机械臂法兰。早期模型按可能存在约 3 mm 垫片建立占位；现场现认为可能没有该垫片，尚未在拆装状态下确认。

参考 `/home/industio/YDI-J22柔性机械夹爪-三维模型/舵机四指尺寸图.jpg`：图示最大展开 166 mm、图示高度 160 mm、侧面总宽 80.59 mm、底板 56×56 mm。STEP 已确认存在，本版未转换或导入精细 CAD，而使用基本几何体作为占位。

参数在 MoveIt URDF xacro 中，单位为米/弧度：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `gripper_mount_xyz` | `0 0 0` | 与控制器 `flange_link` 原点重合 |
| `gripper_mount_rpy` | `0 0 0` | 与 `flange_link` 同向 |
| `gripper_spacer` | `0.003` | 历史占位值；实物是否存在待确认，不参与标定 TCP |
| `gripper_tcp_from_body_xyz` | `-0.000847397 0.003027928 0.175` | 相对夹爪本体；与 3 mm 占位相加后得到法兰 TCP Z=178 mm |
| `gripper_tcp_rpy` | `0 0 0` | 机械同轴定义 |
| `gripper_envelope_x/y/z` | `0.180 / 0.100 / 0.200` | 初版占位包络尺寸，并非厂家认证的全行程包络 |

控制器 `flange_link` 已通过多姿态 FK 交叉核对。垫片占位平面尺寸暂用 56×56 mm，但其存在性不再用于推导 TCP。

当前四指外观只表达“装有四指夹爪”，尺寸和姿态不代表完整连杆运动。盒形 collision 包住整个夹爪，包括中间开口，适合先做净空/本体碰撞验证。它会阻止目标物进入夹取空间，因此正式抓取前应拆分本体与手指碰撞几何，并只对抓取目标与预期接触部位配置接触规则。不能全局关闭夹爪碰撞来绕过此问题。

2026-09-10 已采集 12 个固定点姿态。全量求解在排除第 11 组后得到 X/Y=`[-0.847397,3.027928] mm`，但 Z=184.614 mm 与实物不符；最终按用户直接测得的法兰盘到尖端距离 178 mm，冻结 `flange_link -> grasp_frame = xyz[-0.000847397,0.003027928,0.178] m, rpy[0,0,0]`。厂商已说明原 160 mm 尺寸有问题，不再使用。该实用 TCP v2 已接入 MoveIt/MTC；机器可读结果见 `src/fairino3mt_v6_moveit2_config/config/ydi_j22_tcp.yaml`，完整步骤见 `docs/calibration/FR3C夹爪TCP固定点标定采集说明.md`。控制器专用 tool ID、负载重量/质心和 P10 的 20 次抓放仍待完成。

## 限位与碰撞的区别

- URDF 六轴 lower/upper：限制单关节角度；MoveIt 的速度设置另见 `joint_limits.yaml`。这些值没有被本次修改。
- 本体碰撞：检查几何体是否相交；两个合法关节角组合仍可能使手臂折叠碰到自身。
- 环境碰撞：桌面、料框等必须另行加入 PlanningScene 才能被检测，RViz 背景网格不是实体桌面。
- 控制器软限位/碰撞保护：控制器侧机制，不能因 ROS 模型补齐就认为已经配置或验证。

## 生效方式

相关两个包已构建通过。在原运行环境停止当前 demo/MoveIt/RViz 后重新启动，并确保终端 source 本工作区 `install/setup.bash`；已经运行的节点不会自动重载磁盘上的 URDF。不要在已有控制栈上叠加启动第二套。

在 RViz MotionPlanning 的 Planning Request 下可开启 Collision Geometry 查看碰撞包络；不同显示项布局可能不同，也可用 RobotModel 的 Collision Enabled。原有启动方式不变。

## 离线验证

`test/model_collision` 是只加载模型的 C++ 检查程序，不创建机器人控制节点，不执行轨迹。`COLCON_IGNORE` 避免它进入常规工作区构建。

```bash
cd /home/industio/fairino_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
cmake -S test/model_collision -B /tmp/fr3c_collision_build
cmake --build /tmp/fr3c_collision_build -j2
xacro src/fairino3mt_v6_moveit2_config/config/fairino3mt_v6_robot.urdf.xacro initial_positions_file:=/home/industio/fairino_ws/src/fairino3mt_v6_moveit2_config/config/initial_positions.yaml > /tmp/fr3c_with_gripper.urdf
/tmp/fr3c_collision_build/check_model /tmp/fr3c_with_gripper.urdf src/fairino3mt_v6_moveit2_config/config/fairino3mt_v6_robot.srdf
```

已验证：机械臂规划组仍严格为 6 个可动变量且包含 `grasp_frame`；默认姿态、pos1、pos2 无自碰撞；确定性随机采样找到关节限位内的自碰撞状态；全部 7 个本体连杆、垫片和夹爪均能检测到放在对应位置的测试障碍物；远处障碍物无接触。此检查证明 TCP/碰撞链路生效，不是穷举验证所有姿态，也不替代安装标定和真实环境建模。

## Gemini Pro 相机外壳占位（2026-09-08）

根据用户提供的六张实物/界面照片和外壳实测尺寸，增加 `gemini_pro_placeholder.xacro`。黑色长方体外观为 100×35×20 mm；碰撞盒每侧加 3 mm，合计 106×41×26 mm。尺寸轴约定为 X=长、Y=高、Z=厚。

相机通过固定关节连接 `gripper_mount_link`（名义法兰安装坐标），不是连接到可动手指。中心位置为 `(0, -0.0575, 0.015)` m：在法兰平面内向实物相机所在的 -Y 侧偏移 57.5 mm，沿工具伸出方向偏移 15 mm。早期照片估计曾暂用 +Y，2026-09-11 经 RViz 与实物方位核对确认落在法兰对侧，现已修正 Y 符号。此次只修位置，没有无依据地给相机自身增加 180°旋转。

上述安装参数、三个尺寸和 `camera_collision_padding` 位于 MoveIt 配置包的 `fairino3mt_v6_robot.urdf.xacro`。这个外壳坐标不是相机光学坐标，不应作为手眼标定结果。本次只添加用户要求的外壳盒，未建模支架、转接板与线缆；3 mm 余量也不表示已覆盖安装估计误差。

不改变关节限位或控制插件。相机与机械臂本体、环境保持碰撞检查；相机与固定夹爪占位包络的局部重叠单独排除，见下文。重新启动原有 demo/MoveIt/RViz 环境即可加载。

相机加入后的验证结果：两个相关包构建通过，已安装的 MoveIt 配置能加载相机；默认姿态、pos1、pos2 无自碰撞；随机采样检测到角度限位内的 `camera_housing_link/forearm_link` 自碰撞；相机位置测试障碍物能检测到，远处障碍物无接触。未连接或驱动真机。

### 相机底面贴合法兰外缘修正

用户确认相机底面与法兰外缘相切。以模型名义半径 40 mm、相机半高 17.5 mm 计算中心高度 57.5 mm；原 75 mm 估位使底面悬空约 17.5 mm，现下移该距离。轴向 15 mm 偏移保留，实际转接盘半径仍需实测核对。

相切安装后，相机碰撞盒与夹爪“填满整个开口”的固定大包络在根部相交。这是当前占位几何的重叠，SRDF 仅增加 `camera_housing_link/gripper_link` 安装组件对的碰撞排除；没有关闭相机与腕部、前臂及其他机械臂连杆或环境的检测。后续将夹爪改为可动手指模型时须重新审查此规则。
