## 日常启动和操作

先关闭旧的 `start_preview.sh`、`start_follow.sh`、第三步伺服程序，以及上一次 Demo 的启动终端。已有相机和标签节点可以继续运行。

```bash
cd /home/industio/fairino_ws
scripts/target_follow/start_demo.sh
```

默认 ROS 域 187。入口按实际发布者复用相机、检测节点；缺少相机时执行已有设备预检再启动，缺少检测时只补检测。已有完整执行链路时提示关闭旧链路，避免建立第二个 SDK 所有者。若相机运行在其他域，用 `FR3C_FOLLOW_DOMAIN_ID=实际域` 在同一域启动。

不传防碰撞开关时读取参数文件，当前默认文件为 `collision_enabled: false`，使用加入模型检查之前的跟踪流程。无需额外启动 move_group、ros2_control 或点云节点。

执行端启动后是待机，启动入口不会自动发送伺服运动。机械臂已处于自动模式、使能状态，标签可见且末端处于合适位置时：

| 操作 | 行为 |
| --- | --- |
| T | 停止时记录当前 TCP 到标签的固定偏移，不触发运动 |
| S | 重新记录当前偏移和末端旋转，再开始 XYZ 跟随；可以直接按 S，无须先 T |
| X | 主动停止跟随，之后不会自动恢复；再次 S 开始新一轮 |
| Q / Esc / 窗口关闭按钮 | 关闭 **本次 Demo 打开的** 查看器，同时结束 Demo 和执行端 |
| 启动终端 Ctrl-C | 停止伺服、关闭 SDK，再退出本次启动的节点 |

目标短暂丢失后执行端停止推进；新鲜目标回到当前跟随范围时保留原偏移平滑恢复。范围、反馈或 SDK 故障按现有执行端规则处理；查看器显示具体原因，处理后关闭并重新运行 Demo，再按 S。

查看器保留目标、实际 TCP、期望 TCP、位置误差和速度，显示观测/反馈年龄、SDK 停止返回码和操作结果。图像或执行状态不新鲜时会提示。

本次启动的节点随 Demo 退出；复用的独立相机、标签节点和查看器保持运行。若复用了旧查看器，关闭旧窗口只会关闭显示，使用 Demo 终端 Ctrl-C 结束执行端。原有 `view_pose.sh` 单独运行时，Q/Esc 也只关闭显示；源码更新后重开窗口才能加载新版显示。

## 防碰撞模式与当前参数

两种启动模式选择一种。明确关闭新增模型检查：

```bash
scripts/target_follow/start_demo.sh collision_enabled:=false
```

开启机器人、夹爪、相机附件与固定工作台的模型检查：

```bash
scripts/target_follow/start_demo.sh collision_enabled:=true
```

命令行显式 true/false 优先于参数文件；不传或传 `collision_enabled:=auto` 时读取文件。切换顺序为 **X/stop 停止 → Ctrl-C 退出 Demo → 按所选模式重新启动 → S 记录新偏移并开始**。启动后开关只读，运行中 `ros2 param set` 会被拒绝。分终端入口 `start_follow.sh` 接受同一开关，切换时只需停止并重启执行端。

| 当前模式 | 查看器显示 | `follow_control.sh status` 中的字段 |
| --- | --- | --- |
| 关闭模型检查 | `Model collision: OFF` | `tracking_mode: legacy`，`collision.enabled: false` |
| 开启模型检查 | `Model collision: ON`，附带检查信息或 waiting | `tracking_mode: collision_guarded`，`collision.enabled: true` |

关闭模式不加载碰撞模型、不启动预测逆解和检查线程，保留原有反馈超时、控制器故障/碰撞状态、目标丢失、范围限制和停止处理；不会进行模型自碰撞或桌面预检。这个开关不修改控制器自身的碰撞检测设置。

开启模式接近模型障碍时减速，进入预测余量或没有有效检查结果时进入 `paused_collision`；目标转向可检查的退离方向后，保留原偏移恢复。检查等待或过期也会暂停，不能把每次暂停理解为已发生实物碰撞。此前开启模式尤其 Z 上升时出现过频繁启停，目前保留该算法，未确认卡顿已经解决。

开启前核对 `table_z_m`：它是桌面相对 `base_link` 的高度，当前为 0.0 m；工作台模型为以基坐标原点为中心的 2×2 m 固定平面，不接入点云或深度场景。完整模型说明、暂停原因和分终端流程见 [轻量防碰撞使用说明](./目标跟踪轻量防碰撞使用说明-20261008.md)。

两种模式共用 `/home/industio/fairino_ws/src/fr3c_follow_driver/config/position_follow.yaml` 的控制参数，2026-10-09 核对值如下：

| 参数 | 当前配置 | 含义 |
| --- | --- | --- |
| `kp` | 2.0 /s | 位置比例增益 |
| `max_speed_m_s` | 0.020 | 速度上限 20 mm/s |
| `max_accel_m_s2` | 0.060 | 加速度上限 60 mm/s² |
| `follow_radius_m` | 1.00 | 每轮开始时实际 TCP 周围半径 1 m |
| `target_timeout_s` | 0.35 | 目标观测超时 350 ms |
| `feedback_timeout_s` | 0.20 | 机械臂反馈超时 200 ms |

范围按期望 TCP 相对本轮起始 TCP 的三维直线距离判断。第四步首轮记录中的 100 mm 是当时的配置，当前已为 1 m；该范围不代表模型防碰撞能力。数值以实际加载的配置为准，按现场空间调整后重启加载，不是新增验收指标。姿态仍只用于显示，末端保持开始时的旋转。

## 命令行操作

无桌面时自动不启动查看器，也可主动禁用：

```bash
scripts/target_follow/start_demo.sh --no-view
```

同域另一个终端：

```bash
scripts/target_follow/follow_control.sh status
scripts/target_follow/follow_control.sh teach
scripts/target_follow/follow_control.sh start
scripts/target_follow/follow_control.sh stop
```

`status` 输出执行状态、实际/期望 TCP、误差、观测年龄、暂停原因和已记录的停止返回码。`stop` 在收到驱动停止状态后显示 SDK 停止结果。服务未运行、操作被拒绝或响应未到达时，命令报出原因并返回非零，不无限等待。

## 日志和关闭

每次启动在 `evidence/target_follow/stage5/日期时间_PID/` 保存：

- `session.json`：ROS 域、是否模拟、复用和启动的数据源、执行参数文件及 `collision_enabled_selection`（auto/true/false）。
- `samples.jsonl`：沿用执行端的实际 TCP、期望 TCP、误差状态、观测年龄、发送节拍和 SDK 返回码。
- `report.json`：执行端退出后生成的汇总、实际 `collision_enabled` / `tracking_mode`、发送数量、碰撞暂停/恢复次数及停止/关闭结果。
- `ros_logs/`：本次启动的节点日志和终端操作结果。

`live_follow_validated` 不会因模拟运行或内部误差小而自动变为 true。现场效果依据第四步已有实机记录和用户确认，第五步的软件验证另行记录。

`session.json` 的 auto 表示读取参数文件，不等于已开启模型检查。实际模式以实时状态或 `report.json` 为准；关闭模式没有模型检查耗时，`collision_check_ms` 为 null。开启模式可结合 `collision.reason`、检查年龄和暂停次数定位卡顿。

```bash
scripts/target_follow/start_demo.sh --mock --no-view
scripts/target_follow/follow_control.sh status --mock
```

模拟默认域 189，使用 MockClient，不自动打开真实相机，也不自动生成模拟标签；没有外部测试图像/标签时保持待机。Ctrl-C 退出即可，不要求运行一分钟。
