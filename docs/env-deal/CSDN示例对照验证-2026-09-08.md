# CSDN 示例对照验证（2026-09-08）

参考：https://blog.csdn.net/2301_78767880/article/details/147323555

## 结论

当前系统 Ubuntu 22.04.5 / ROS 2 Humble。MoveIt core 2.5.9、MTC core/capabilities/visualization 0.1.3 均由 `/opt/ros/humble` 提供，controller_manager 为 2.54.0。项目包由本工作空间 install 提供。这种依赖布局可用，无需将 MoveIt 源码复制到项目中。

本次未修改业务源码；验证使用 ROS_DOMAIN_ID=187、ROS_LOCALHOST_ONLY=1，启动前解析实际加载的 URDF，确认唯一硬件插件为 mock_components/GenericSystem。未连接或驱动实体机器人。测试进程已退出。

## 实测

- `MAKEFLAGS=-j1 CMAKE_BUILD_PARALLEL_LEVEL=1 colcon build --executor sequential --cmake-args -DBUILD_TESTING=OFF`：5 个包全部成功（增量编译，非清空后的完整重编译）。
- `mtc_demo_env.launch.py use_rviz:=false`：环境启动，fairino3mt_controller 与 joint_state_broadcaster 均 active。
- `mtc_demo_app.launch.py`：Task planning SUCCESS (execution disabled)。
- `mtc_demo_app.launch.py execute:=true cycle_count:=1`：Task execution SUCCESS 与 Reverse Task execution SUCCESS。
- 测试为无界面模拟验证，未验证 RViz 实际显示和实体机器人运动。
- 原始输出位于 `log/csdn_validation/{environment,controllers,planning,execution}.log`。

## 替换来源

用户给出的 GitHub `src/build/fairino_mtc_demo` 是编译目录，其 CMakeCache 含上游计算机绝对路径及 x86_64 库路径，不应复制使用。

实际源码：https://github.com/Chranos/ros2_robotarm/tree/main/src/frcobot_ros2-3.0.0_RobotV3.7.7/fairino_mtc_demo

上游为 FR5 配置、相对运动 0.1–0.2 m、循环 1000 次。本地为完整源码包，已改为 fairino3mt_v6_robot / fairino3mt_v6_group / fairino3mt_controller，增加 pos1 准备位，使用 0.002–0.004 m 相对运动，默认仅规划、单次循环。因此兼容性验证通过，但不等于复现了上游完整抓取轨迹。

## 仍存在的问题

1. 展开的机器人 URDF 中 collision 元素数量为 0；MoveIt 明确输出所有机器人连杆无碰撞几何。机器人本体的自碰撞和环境碰撞检测不完整，需补模型后再验证真实抓取路径。
2. MTC 仅 attach/detach 场景物体，无真实夹爪命令；物体位姿、TCP、准备位和短行程尚不能代表标定后的抓取任务。
3. joint_limits.yaml 未启用加速度限制，运行时采用默认 1 rad/s²。需按实际机器人参数配置。
4. 未配置 Octomap 传感器插件，日志报 No 3D sensor plugin(s) defined；不妨碍本次静态场景模拟，但没有深度感知更新。
5. 实机硬件接口还有待修复/验证的代码问题：read() 使用仅在 on_activate() 创建的 _ptr_robot，缺少未激活时保护；write() 的 std::any_of 结束指针为数组第 6 项地址，实际漏检第 6 项；ServoJ 失败仅记录日志仍返回 OK；控制器周期为 10 ms，而 ServoJ 参数为 8 ms，需按 SDK 时序要求核对。没有通过切换真实硬件插件进行测试。
6. MTC main 在规划/执行失败后 break，最后仍 return 0；自动化验证应检查 SUCCESS 日志，不能仅检查退出码。本次同时检查了成功日志。

## 日常启动

两个终端均先运行：

```bash
source /opt/ros/humble/setup.bash
source /home/industio/fairino_ws/install/setup.bash
```

终端一：

```bash
ros2 launch fairino_mtc_demo mtc_demo_env.launch.py
```

终端二（仅规划）：

```bash
ros2 launch fairino_mtc_demo mtc_demo_app.launch.py
```

CSDN 使用的 FR3 包名需替换成本项目的 fairino3mt_v6_moveit2_config。当前阶段保持 mock 插件；后续配置修改应以 src 中源文件为准并重新构建，不应照教程直接修改 install 中的副本来维护配置。
